# Exploratory Data Analysis Using Python

## Project Overview
This project performs Exploratory Data Analysis (EDA) on the Crime Dataset using Python.

## Dataset
- Dataset: Crime.csv
- Number of records: 630
- Original number of columns: 45

## Libraries Used
- Pandas
- NumPy
- Matplotlib
- Seaborn
- SciPy
- Scikit-learn

## Assessments Covered
1. DataFrame Operations, Merging and Normalization
2. Data Inspection, Cleaning and Descriptive Statistics
3. Univariate Analysis and Outlier Detection
4. Bivariate Analysis
5. Multivariate Analysis
6. Time Series Analysis
7. Summary Statistics and Data Comparison
8. Clustering Analysis
9. Principal Component Analysis (PCA)
